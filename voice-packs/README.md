# Cortana community voice pack for Roborock S5

94 spoken announcements and 2 chimes. Intended for the original S5/S50/S55 running Valetudo, not S5 Max. This uses a community Piper model labelled Cortana; its included model card does not establish Halo provenance. Format and package integrity checks passed; physical S5 playback remains untested.

Model source: https://github.com/drycen/piper-tts-voices/blob/main/en_US-cortana-medium.zip

Valetudo custom voice pack language code: VA
MD5: 1e32c9956ca9e3c23530ced38986b067

Back up the current voice pack before installation. Use the direct raw URL for cortana-s5.pkg in this branch, then enter VA and the MD5 in Valetudo's voice-pack screen. Selecting stock English (en) can ignore the custom URL in current Valetudo.
